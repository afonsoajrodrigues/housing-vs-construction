# Portugal's House Prices Are Rising Twice as Fast as the Cost to Build Them

A data journalism piece comparing Portugal's house-price index (Eurostat) against its construction-cost index (INE) from 2020 to 2025, with a country comparison across eight European economies and sourced context on why the gap has widened.

**Read it:** https://afonsoajrodrigues.github.io/portugal-habitacao-vs-construcao/

## Contents

- `index.html` — the article
- `assets/chart-price-vs-cost.svg` — Portugal's house-price index vs. construction-cost index, 2020–2025
- `assets/chart-country-growth.svg` — house-price growth by country, 2020–2025
- `assets/map.html` — interactive map of house-price growth across Europe
- `code/` — the Python scripts that produced the charts and the map, plus the data they use
- `SCRAPING.md` — how the underlying data was originally collected, before it ever reached `code/`

## How the data was collected

The raw numbers in `code/data/` (Eurostat's house price index, INE's
construction cost index) came out of a separate project practicing web
scraping and public-data APIs — static HTML parsing, browser automation,
Scrapy, and reverse-engineering official statistical APIs (INE, Eurostat,
World Bank, UN, NASA, the EU open data portal). The full write-up of that
process is in **[SCRAPING.md](SCRAPING.md)**.

## How the charts and the map were made

Everything in `assets/` was generated by the scripts in `code/`, in this order:

1. `code/process_data.py` — reads the raw CSV files in `code/data/`, puts
   both indices on the same 2020 = 100 scale, and works out the growth
   rate per country.
2. `code/make_charts.py` — builds the two SVG charts from the cleaned data.
3. `code/make_map.py` — builds the interactive map from the cleaned data
   and `code/data/country_borders.json`.

To run it yourself:

```bash
cd code
pip install pandas
python process_data.py
python make_charts.py
python make_map.py
```

This is a personal/student project, so the scripts are kept plain on
purpose — no charting library, no map library, just pandas for the data
and plain loops that build SVG/HTML text directly.

## Data & sources

Primary data: [Eurostat house price index](https://ec.europa.eu/eurostat/databrowser/view/prc_hpi_a) (prc_hpi_a) and [INE](https://www.ine.pt) (Portugal's national statistics institute), construction cost index for new housing. Full source list for the explanatory reporting is in the article itself.

Country borders on the map: [Natural Earth](https://www.naturalearthdata.com/) 1:110m (public domain), via [world-atlas](https://github.com/topojson/world-atlas).
